# 競馬「投資」システム — 6/20 阪神 戦略パッケージ

ギャンブルではなく**投資**として競馬に向き合うための、期待値判定・資金管理・記録の一式。
「当てる」ためではなく、**長期で破産せず、控除率を上回る妙味（オーバーレイ）だけに資金を配分する**ための道具です。

---

## 0. 最重要の前提（プロが最初に受け入れること）

- **「絶対に負けない馬券」は数学的に存在しません。** JRAの控除率は券種により約20〜30%。買った瞬間に期待値はマイナスから始まります。
- 利益の源泉は「当て続けること」ではなく「**自分の見積もり勝率 × オッズ > 1.0** の状況だけを選んで張り、それ以外を全部見送ること」。
- したがって本パッケージのゴールは **「破産確率を限りなく0に近づけ、期待値プラスの場面だけに資金を置く」** です。

## 1. 6/20(土) 阪神について（確認できた事実と、できなかった事実）

**確認できたこと**
- 6/13(土)=3回阪神3日、6/14(日)=3回阪神4日（宝塚記念GI）。開催日数から **6/20(土)・21(日) は阪神開催（3回阪神5日・6日相当）で実在**。
- この週末の阪神の牝馬限定ハンデ重賞は **マーメイドステークス（GⅢ・芝2000m）** が有力。
- 「神戸」は **ウインズ神戸（場外発売所）** として実在。神戸から阪神レースを買える。

**確認できなかったこと（正直に明記）**

  → **当日 JRA公式アプリ / JRA-VAN / netkeiba で出走表を開き、本システムに入力してください。**
  出馬表は前日（金）に枠順確定、確定オッズと馬体重は当日。

## 2. 当日の資金配分（バジェット法）

| 項目 | 1万円バジェット | 10万円バジェット |
|---|---|---|
| 当日の総投下上限 | 資金の20% = **2,000円** | 資金の12% = **12,000円** |
| 1レースあたり | 500〜1,000円 | 3,000〜5,000円 |
| 厳選レース数/日 | **1〜2鞍** | **2〜4鞍** |
| 1点あたり上限 | 資金の6%以内 | 資金の6%以内 |
| 損切りライン | 当日 **−1,000円** で即終了 | 当日 **−4,000円** で即終了 |
| 全レース購入 | **しない** | **しない** |

ステーク手法は **1/4ケリー**（フルケリーは破産確率が高いので使わない）。
券種は控除率の低い **複勝・ワイド中心**。三連単は「宝くじ枠」（総額の10%以内）まで。

## 3. マーメイドS（ハンデ重賞）の攻め方

- ハンデ戦＝オッズが荒れやすい＝**オーバーレイが生まれやすい**＝投資妙味が出やすい。
- ただし荒れる＝予測精度が落ちるので、**軸1頭の複勝＋相手2〜3頭のワイド**で破産せず妙味を拾う。
- 着目点：①上位人気に資金が過剰集中していないか（過剰なら期待値消失→買わない）、②トップハンデの人気馬は割引・軽ハンデで前走好走の中位人気を狙う、③阪神芝2000m内回りは先行有利になりやすい、④当日の天候→馬場で内外の有利が変わる。

## 4. X（旧Twitter）情報の扱い

- 有料予想・「鉄板」「確定情報」は**逆指標／ノイズ**。当たった週だけ宣伝される生存者バイアス。
- 使うのは一次情報のみ：①厩舎・調教師コメント、②当日の馬体重・パドック、③天候→馬場。
- 正しい使い方：Xで**過剰人気が集まっている馬を特定し、その裏（過小評価された馬）**を狙う。

## 5. ファイル構成と使い方

| ファイル | 役割 |
|---|---|
| `競馬投資ダッシュボード.html` | **当日スマホで開く本体。** 馬番・オッズ・見積勝率を入れると、賭け額と買い/見送りを自動判定。ネット不要・単体で動く。 |
| `value_engine.py` | 同ロジックのCLI版。`python3 value_engine.py` |
| `bankroll_sim.py` | 破産確率モンテカルロ。`python3 bankroll_sim.py`（戦略の安全性を数値で検証） |
| `bet_log.csv` | 収支記録テンプレ。全ベットを記録し、回収率・的中率を後で検証する。 |

### 当日の手順
1. JRAアプリで6/20阪神の出走表・確定オッズを確認。
2. `競馬投資ダッシュボード.html` をスマホで開く。
3. バジェット（1万/10万）を選択。
4. 妙味を感じる馬の「馬番・オッズ・**自分の見積勝率**」を入力。
5. BUTと表示され、当日上限内の馬にだけ、表示額を投下。
6. 1レース終わるごとに `bet_log.csv` に記録。損切りラインに触れたら**即終了**。

## 6. シミュレーションが示す教訓（`bankroll_sim.py` の出力より）

- 回収率0.80（妙味なし）で全レース買う → **破産確率 約99%**。何をしても溶ける。
- 回収率1.05（妙味あり）× 厳選 × 低比率フラット → **破産確率ほぼ0%、プラス収支で終える確率 約55%**。
- 同じ妙味でも1点15%張りにすると → **破産確率 約60%**。賭けすぎが最大の敵。

> 結論：**勝敗を決めるのは買い目より資金管理。厳選して見送る規律こそが、10年続く投資家と1日で溶かすギャンブラーの差。**
